# Brief Description
tg-ctrl allows you to remotely control your operating system through a Telegram bot. Setup is simple — you only need the bot token and your Telegram ID. The bot lets you shut down the PC, take screenshots, control volume, launch files and folders, display custom windows, and more. It’s convenient, fast, and secure.
# Installation
Go to the [Releases](https://github.com/iquldev/tg-ctrl/releases) section and download the installer. Install the program to any folder.
## Autorun
If for some reason the program wasn’t added to startup, press Win+R and type shell:startup, then place a shortcut to the program in that folder.
## Silent Launch
If you don’t want a window to pop up at launch, add the --silent argument to the shortcut.
